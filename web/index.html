引用论文所属单位

每家单位按不同引用论文计数。同一论文的多位作者、或它引用你的多篇论文，在该单位下都只计一次。包含首次导入；一篇多单位论文可计入多家单位。

引用作者

按匹配论文中记录的作者姓名汇总，同名作者可能合并。

如何理解这些数据

1. Scholar 总引用数来自作者主页；详情来自 Google Scholar Cited By。计数和具体论文列表可能不同步。

2. 首次收集每篇目标论文的引用列表，标记为“首次导入”。之后才把未见过的引用关系标记为“后续新发现”。初始分页尚未完成期间，所有结果仍归入首次导入。

3. “发现时间”是系统看到这条引用的时间，不是论文发表时间、引用发生时间，也不表示这条引用恰好贡献了当天的 +1。

4. 单位来自 OpenAlex 的该篇论文作者记录，可能缺失或有误。标题、作者与年份匹配只是自动判断；页面保留来源与匹配依据供你核验。未匹配时保留 Scholar 原文，不推断单位。

5. 引用数变化时查详情；每隔 7 天也重新扫描，捕捉引用数不变但列表改变的情况。超过分页或请求上限时，结果会保留，并在下一轮继续。

6. 已保存的记录是历史观察，不保证今天仍被 Scholar 收录。该版本不判断自引，不读取引用上下文，不按实验室推断归属。

7. GitHub Actions 每天自动抓取并发布。手动抓取请到仓库 Actions → Daily citations → Run workflow；页面刷新只读取已发布的数据。

Scholar 提供计数与引用关系 · OpenAlex 提供元数据 · 无 LLM 调用
